# ChatGPT & Codex Launcher v0.3.0

Released 2026-10-08.

The first public package of Jack's accepted v0.3 launcher: a small floating Windows widget that switches an already-open ChatGPT desktop app between ChatGPT and Codex.

The branding update on **2026-10-08** changes the public name, default button labels, display text, and comments. The accepted launcher and EDIT behavior are preserved, and the version remains **v0.3.0**.

## Download

- **ChatGPT-Codex-Launcher-v0.3.0-Windows.zip** — portable launcher, source, documentation, and release builder.
- **SHA256SUMS.txt** — checksums for verifying the release download.

Get these files from the [GitHub release page](https://github.com/Wilsonious/chatgpt-codex-launcher/releases/tag/v0.3.0).

## Run it

Review the source, unblock the ZIP in its Properties window if needed and trusted, then extract it. Open and sign in to the ChatGPT Windows desktop app, then double-click **Start-Launcher.cmd** in the extracted folder.

Requires Windows PowerShell 5.1, .NET Framework/WPF, Windows Script Host, and a writable roaming application-data folder. No installer, third-party modules, or API keys are needed.

## What's included

- The v0.3 PowerShell source, with public labels and its accepted functionality preserved.
- A double-click launch helper and a repeatable release builder included in the ZIP.
- Documentation, rendered interface previews, and the MIT license.

The original launcher and edit controls were live-tested by Jack on his Windows PC. Other Windows and ChatGPT app versions have not yet been independently validated.

## Before using it

The blue ChatGPT button sends **Alt+3**; the purple Codex button sends **Alt+1**. These mappings selected ChatGPT and Codex on the original tested PC. Check your own app's shortcuts because versions and configurations can differ.

The widget switches an existing ChatGPT desktop window. It does not start the app, open web links, or control a separate standalone Codex application. Its highlight records the last requested mode rather than confirming success.

Existing preferences in `%APPDATA%\NeonChatSelector\settings-v0.3.json` are reused, including saved button names. Fresh settings use **ChatGPT** and **Codex**. No personal settings are included in this package.
