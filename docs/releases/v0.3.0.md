# Tiggy & Mother Launcher v0.3.0

Released 2026-10-08.

The first public package of Jack's accepted v0.3 launcher: a small floating Windows widget that switches an already-open ChatGPT desktop app between Tiggy (ChatGPT) and Mother (Codex).

## Download

- **Tiggy-Mother-Launcher-v0.3.0-Windows.zip** — portable launcher, source, and documentation.
- **SHA256SUMS.txt** — checksums for verifying the release download.

Get these files from the [GitHub release page](https://github.com/Wilsonious/tiggy-mother-launcher/releases/tag/v0.3.0).

## Run it

Review the source, unblock the ZIP in its Properties window if needed and trusted, then extract it. Open and sign in to the ChatGPT Windows desktop app, then double-click **Start-Launcher.cmd** in the extracted folder.

Requires Windows PowerShell 5.1, .NET Framework/WPF, Windows Script Host, and a writable roaming application-data folder. No installer, third-party modules, or API keys are needed.

## What's included

- The accepted v0.3 PowerShell source, with its functionality preserved.
- A double-click launch helper. The repository also provides a repeatable release build.
- Documentation, rendered interface previews, and the MIT license.

The original launcher and edit controls were live-tested by Jack on his Windows PC. Other Windows and ChatGPT app versions have not yet been independently validated.

## Before using it

The blue Tiggy button sends **Alt+3**; the purple Mother button sends **Alt+1**. These mappings selected ChatGPT and Codex on the original tested PC. Check your own app's shortcuts because versions and configurations can differ.

The widget switches an existing ChatGPT desktop window. It does not start the app, open web links, or control a separate standalone Codex application. Its highlight records the last requested mode rather than confirming success.

Existing preferences in `%APPDATA%\NeonChatSelector\settings-v0.3.json` are reused. No personal settings are included in this package.

Read the [README](https://github.com/Wilsonious/tiggy-mother-launcher/blob/v0.3.0/README.md), [customization guide](https://github.com/Wilsonious/tiggy-mother-launcher/blob/v0.3.0/docs/CUSTOMIZATION.md), and [security notes](https://github.com/Wilsonious/tiggy-mother-launcher/blob/v0.3.0/docs/SECURITY.md) for details.
